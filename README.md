# 🎬 Color ASCII Video Converter

A lightweight desktop GUI application built with Python that converts video files into **colored ASCII art** with real-time preview and MP4 export.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-Video%20Processing-green?logo=opencv&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-orange)

## ✨ Features

- **Dark Mode GUI:** Clean interface built with `tkinter` — no code editing required.
- **Real-Time Preview:** Watch the colored ASCII rendering live inside the window.
- **Customizable Output:** Adjust maximum clip duration (seconds) and character width (resolution/detail).
- **MP4 Export:** Automatically saves the rendered ASCII animation as `<filename>_ascii.mp4`.
- **Multi-Format Support:** Works with `.mp4`, `.avi`, `.mov`, `.mkv`, and `.webm`.
